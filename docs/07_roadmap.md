# Purpose

This document defines the planned evolution of the Life Milestone Tracker project.

It focuses on functional goals rather than implementation details.

Technical design, database schema and API specifications are documented in separate files.

---

# Product Vision

Life Milestone Tracker aims to become a lightweight personal productivity platform for tracking long-term progress across different areas of life.

The project evolves gradually.

Each released version must remain:

- usable
- stable
- documented
- maintainable

# Guiding Principles

Future features should satisfy at least one of the following goals:

- improve usability
- improve maintainability
- improve data quality
- improve scalability

Features are not added simply because they are technically possible.

---

# Out of Scope

The following items are intentionally excluded unless future requirements justify them:

- social networking
- gamification
- advertising
- unnecessary complexity
- enterprise-level infrastructure
