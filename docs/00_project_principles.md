# Purpose

This document defines the fundamental principles that guide the design and implementation of the Life Milestone Tracker project.

These principles take precedence over implementation details.

---

# Principles

1. Design before implementation.

2. Documentation is the source of truth.

3. Refactoring is performed only after Version 1.0 is stable.

4. Business logic is independent from the storage engine.

5. Derived values are never persisted.

6. Every entity has a single responsibility.

7. Keep the design simple.

8. Avoid unnecessary abstraction.

9. Version 1.0 is a single-user application.

10. Data model changes must be documented before implementation.

11. Every implementation must follow the documented data model.
