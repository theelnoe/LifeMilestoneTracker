# Life Milestone Tracker

A lightweight Flask application for tracking long-term learning, research, and personal development goals.

## Features

- Multiple projects
- Stopwatch timer
- Manual time entry
- Milestone progress bar
- Daily statistics
- Weekly statistics
- Session history
- Responsive interface

## Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/theelnoe/LifeMilestoneTracker.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Then open:

```
http://127.0.0.1:5000
```
